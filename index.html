Git - лучшая система контроля версий. Она позволяет отслеживать изменения в коде и работать в команде без страха что то сломать.

Как посмотреть изменения в репозитории GitHub

  • 1. Открой свой репозиторий на GitHub
  • 2. Нажми на ссылку с колличеством коммитов(например, <<3 commits>>) сверзу страницы
  • Либо нажмит на вкладку Commits
  • Нажми на хэш коммита (например, а1б2в3г4), чтобы увидеть, что именно здесь изменилось
